# Hilaal Studios — Brand Dashboard

A simple dashboard for planning and launching the Hilaal Studios clothing brand.

**Sections:** Overview (to-dos and brand foundation) · Ideas · References (moodboard) · Spending (budget and expenses) · Ads (campaigns) · Ad Inspo

## Use it

Open `index.html` in a browser. You don't need to install anything.

To run it from a local server instead:

```
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Your data

Everything is saved in the browser you use it in. It is not sent anywhere.
Use **Export backup** (bottom of the sidebar) now and then to download a copy.
**Import backup** restores a copy or moves your data to another computer.

Images can be uploaded, pasted (Ctrl/Cmd+V) into the edit window, or added as an image link.
